Sitsostyle Atelier

Website Planning Document | Custom Garment Commission Request & Sizing Guide

Site Name

Name: Sitsostyle Atelier

Reasoning: I chose this subject because custom fashion requires clear communication and precise measurement tools, giving me a great opportunity to apply conditional JavaScript logic, user input handling, and form event listeners. The name combines my brand identity with 'Atelier' to highlight custom tailoring and bespoke design services.

Site Purpose

The site serves as an informational platform for a bespoke fashion studio offering custom-tailored garments. It provides a showcase of previous custom projects, a step-by-step custom order workflow, and a detailed garment measurement guide. Additionally, it features interactive JavaScript tools including a Measurement & Fit Assistant and a custom commission cost estimator.

Target Audience Scenarios

  • Scenario 1: How can I accurately convert my body measurements between inches and centimeters to get a recommended fit before placing a custom order?
  • Scenario 2: What is the estimated cost of a custom garment commission based on my choice of fabric type and design complexity?

Color Schema

The site uses a refined palette featuring deep navy blue for structure, warm gold for accents, and neutral tones for optimal contrast and readability.

Primary (#0d233a)

Header backgrounds, major titles, primary buttons.

Accent (#d4af37)

Borders, highlight elements, interactive CTA highlights.

Background (#f8f9fa)

Main canvas background to ensure clean text legibility.

Typography

  • Heading Font: Montserrat (Bold 700 / Semi-Bold 600) – Used for primary headers, section titles, and branding.
  • Body Font: Open Sans (Regular 400) – Used for paragraphs, measurement instructions, and form input labels.
